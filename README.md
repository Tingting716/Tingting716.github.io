# 硅序漫谈｜了解AI

一份面向大学生的 HTML 伴学作品，与《人工智能通识及应用》（唐郑熠、林江宏、王金水 主编，高等教育出版社）十章结构对应。它把“读教材”扩展为“讲解—可视化—典型情境—即时练习—进度记录”的自学流程，并围绕 AI 与司法、生成式 AI 与信息生态、全球 AI 治理等议题做公开资料扩展。

- 5 个学习模块：基础与历史、技术原理、应用实践、跨学科专题、素养与行动
- 15 个知识点：每讲都有讲解、可视化框架、典型情境与一道即时反馈练习
- 支持按顺序学习、直接跳转知识点、保存本地学习进度，完全离线运行

## 学习路径

- `learn.html` 将教材 10 章重组为 5 个模块、15 个知识点：基础与历史、技术原理、应用实践、跨学科专题、素养与行动。
- 每个知识点都包含：准确的概念讲解、可视化框架、典型情境，以及一道带即时解析的互动练习。
- 支持三种进入方式：按上一讲 / 下一讲顺序学习、侧边知识点导航直接跳转、移动端下拉选择跳转。
- 练习反馈会立即显示对错与解析；完成状态保存在本机 `localStorage`，刷新后仍保留，不会上传服务器。
- 页面支持 `#p1-ai-definition` 等深链接，可分享到某个具体知识点。

## 交互与适配

- 固定透明页头；滚动超过 40px 后切换浅色毛玻璃与细边框，页头高度不变。
- 768px 以下切换为右侧抽屉菜单；锁定背景滚动，支持 Esc、遮罩关闭。
- 「作品」为点击式超级菜单（项目 / 实验 / 资源 + 精选预览）；移动端转为折叠菜单。
- 首页滚动位置与主导航高亮同步；`about / 知识体系 / 文章 / 联系` 支持页内平滑滚动。
- 作品标签支持点击与左右方向键切换，仅更新作品网格。
- 搜索支持分类筛选、键盘上下选择、Enter 打开与 Esc 关闭。
- 长文章提供阅读进度、文章目录高亮，以及超过 800px 后淡入的返回顶部按钮。
- 系统学习页离线可用，不依赖任何在线接口、CDN 或后端。
- 全站适配 320px、375px、768px 与桌面宽度，无横向溢出。
- 使用系统无衬线字体、内联线性图标、WebP 响应式图片、`defer` 脚本与压缩后的 CSS/JS，无外部框架或字体依赖。
